# Philip Adams — Portfolio

Personal portfolio site for Philip Adams, a software developer specializing in full-stack web development, automation, and AI-integrated workflows.

**Live site:** [https://portfolio-silk-one-sc643kgo7i.vercel.app/]

## About

This site showcases my background and the platforms I've built and worked on, including a two-sided job board built end to end as sole developer, managing a membership platform serving 400+ users, and building several client and freelance projects. It also documents my transition from marine engineering into software development.

## Tech Stack

- HTML5, CSS3, JavaScript
- Google Fonts: Fraunces (display), IBM Plex Mono (labels), Inter (body)
- Planned: Node.js/Express backend with MongoDB, for a working contact form and a live status panel

## Features

- Sticky, responsive navigation with a mobile hamburger menu
- Scroll-anchored sections: About, Work, Journey, Expertise, Contact
- Custom SVG background motif (blueprint/drafting grid) rather than a stock template look
- Fully responsive layout

## Status

Actively in progress. Currently built: navigation and hero section, about section, work section, journey section, expertise section. Remaining sections (Contact) and the backend are being added incrementally.
